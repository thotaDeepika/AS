# Role Based Access Control (RBAC)

## Faculty

### Permissions
- Create appraisal application
- Edit draft applications
- Upload PDF proofs
- Submit applications
- View application status
- Download submitted PDF reports

### Restrictions
- Cannot edit after submission
- Cannot modify scores
- Cannot access other faculty applications

---

## HOD

### Permissions
- View department applications
- Review submissions
- Verify proofs
- Add comments
- Recommend or reject applications

### Restrictions
- Cannot modify scores
- Cannot edit faculty data
- Cannot approve final applications

---

## Reviewer

### Permissions
- View assigned applications
- Verify applications
- Add review comments
- Recommend or reject

### Restrictions
- Cannot edit faculty data
- Cannot edit scores
- Cannot assign reviewers

---

## Principal

### Permissions
- View reviewed applications
- Approve or reject
- Freeze applications

### Restrictions
- Cannot modify application data
- Cannot modify calculated scores

---

## Admin

### Permissions
- Manage users
- Manage departments
- Assign reviewers
- View all applications
- Generate reports
- Manage workflow tracking

### Restrictions
- Cannot override approvals
- Cannot edit faculty appraisal content
- Cannot modify scores

---

## Accounts Department

### Permissions
- View approved applications
- Download reports
- Export data

### Restrictions
- Cannot modify workflow
- Cannot edit applications
